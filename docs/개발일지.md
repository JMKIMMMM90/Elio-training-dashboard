## 2026-09-07 (일~월)

- **교육안내 전면 리뉴얼**: 역량 중심 교육 목적(인내·성실·목표관리·기본기) → 3개 과정 카드(목표↔배점 연결) → 평가 구조 시각화(500점 스택 바 + 주차 100 구성 바 + 가점 자정 기준 명시) 순의 스토리 구조.
- **홈 개편**: 내 점수 요약 카드(실시간)를 오늘의 할 일 위로. 네비 순서 홈→목표관리→교육안내→내 평가.
- **정보구조(IA) 재편**: 한 페이지 스크롤 → 하단 네비 4탭(홈/교육안내/목표관리/내 평가). 홈 = 오늘의 할 일 + 실시간 점수 + 제출함. 관리자는 현황/평가/관리/안내.
- **500점제 도입**: 주차 100×4 + FINAL PPT TEST 100. FINAL은 장수·오류 수만 입력하면 자동 채점(기준 장수·감점단가는 관리 탭 설정). Road to INITIAN 5구간 누적 게이지.
- **평가 체계 확정**: PPT 40(달성률 20 자동+정확성 20) / 책 서평 30(서평 10+달성률 10 자동+책 TEST 10) / 보고서 30(TEST 30). 제출 가점 사다리(2일 전 +5 / 전날 +3 / 정시 0 / 지각 -5)는 만점 외 보너스. 평가 기준을 신입에게 상시 공개.
- **제출물 파일 첨부**: Firebase Storage(Blaze 전환, 무료 위치 버킷). 홈·Day 카드에서 첨부, 평가 탭에서 다운로드. 업로드 시각으로 조기제출 자동 판정.
