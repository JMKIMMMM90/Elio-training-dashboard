# 스킬 폴더

이 프로젝트 전용 Claude Code 스킬이 들어가는 표준 위치. 스킬 하나 = 폴더 하나(`스킬명/SKILL.md`).

예정 스킬 (docs/개발일지.md의 "다음 할 일"과 연동):
- `신입평가/` — 제출물(PPT·서평) AI 초벌 채점 + 오류 로그 축적 → 대표님 승인 → 대시보드 기록
- `수료리포트/` — 교육 종료 시 신입별 4주 데이터를 수료 평가 보고서로 아카이빙

규칙: 스킬이 참조하는 회사 원본 자료(쉐도잉 원본 PPT 등)는 이 저장소(공개)에 두지 않고
로컬 경로를 CLAUDE.md에 기록해 참조한다.
